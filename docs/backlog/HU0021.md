## Enunciado

Como Dirección del colegio quiero crear, modificar y desactivar las cuentas del personal y asignarles un rol (secretaría, Tesorería, psicóloga, evaluador académico o Directora) para que cada persona acceda solo a las funciones y datos que su rol requiere

## Criterios de aceptación

### HU0021-1.0 — Alta de una cuenta del personal

- **Dado (contexto):** En caso que la Directora se encuentra en el módulo de usuarios y roles
- **Cuando (evento):** Cuando registra los nombres, el correo y el rol de un nuevo miembro del personal y confirma
- **Entonces (resultado esperado):** El sistema crea la cuenta con el rol asignado, envía las credenciales al correo registrado y, al iniciar sesión, le muestra únicamente las opciones de ese rol

### HU0021-2.0 — Acceso denegado a información restringida

- **Dado (contexto):** En caso que un usuario con rol de secretaría o de evaluador académico consulta un expediente
- **Cuando (evento):** Cuando intenta abrir la documentación financiera o el informe psicológico
- **Entonces (resultado esperado):** El sistema bloquea el acceso, no muestra el contenido y registra el intento en el registro de auditoría

## Fuera de esta HU

Cualquier comportamiento no descrito en los escenarios anteriores. Si el plan lo necesita, listarlo como *pregunta abierta*, no implementarlo.
