# Licencias de terceros: skills de `.claude/skills/`

Las carpetas de `.claude/skills/` se instalaron con `npx skills add` (ver `skills-lock.json`) desde tres repositorios con licencia MIT. La licencia MIT exige conservar el aviso de copyright y el texto de la licencia en las copias; `npx skills add` no copió el archivo `LICENSE`, así que se conserva aquí.

El texto de cada licencia es el del archivo `LICENSE` de la raíz del repositorio, obtenido de la API de GitHub (`/repos/{repo}/license`) el 2026-10-11, sin modificaciones.
